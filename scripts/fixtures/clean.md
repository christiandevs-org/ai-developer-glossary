## 🛠️ Building & Ops

### Agentic / agent loop

Model runs in a cycle instead of returning one answer.

> "It's not agentic, it's one tool call with good marketing."

**Related terms:** [Eval](#eval)

### Eval

Test suite for non-deterministic output.

## 🔥 Culture & Vibes

### Churn (code)

Lines written then rewritten within a short window. Rising churn is a proxy for wasted motion.

> "Churn doubled this month."

**Related terms:** [Churn (customer)](#churn-customer)

### Churn (customer)

Rate at which users cancel. Month-two churn is where demos go to die.

> "We lose 40% by month two."

**Related terms:** [Churn (code)](#churn-code)

### Cooked

Opposite of "cook" despite the same root. Doomed, broken, unsalvageable.

> "Migration ran against prod. We're cooked."

**Related terms:** [Eval](#eval)
